# Security Policy

## Supported Versions

Security fixes are intended for the latest published application version, currently `1.7.5+13`. Older versions may not receive fixes; update to the latest release where possible.

## Reporting a Vulnerability

Please do not disclose vulnerabilities in public issues or pull requests. Email [muhammadirfan.infosec@gmail.com](mailto:muhammadirfan.infosec@gmail.com) with:

- The affected version and component.
- A concise description and steps to reproduce using test data.
- The potential impact and any suggested mitigation.

Do not include real customer data, passwords, private keys, Firebase service-account files, or signing credentials. The maintainer will acknowledge reports and coordinate any fix and disclosure directly with the reporter.
